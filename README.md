# 20 memórias para Vitória

Um presente digital de aniversário para Vitória Nicoly Santiago Fernandes:
uma central interativa com vinte capítulos, fotografias, músicas, pequenos
segredos e uma carta de encerramento.

## Estado atual

O projeto está em construção. As imagens e músicas já foram catalogadas. Os
textos de cada memória e a carta final poderão ser adicionados depois sem
alterar a estrutura visual.

## Desenvolvimento

Requisitos:

- Node.js 22.13 ou superior
- npm

Comandos:

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

## Conteúdo

O conteúdo editável ficará centralizado em `app/data/memories.ts`. Fotografias
e áudios otimizados ficarão em `public/media`.

## Privacidade

O repositório e o site serão públicos. Nunca inclua senhas, tokens ou outros
segredos nos arquivos versionados.
